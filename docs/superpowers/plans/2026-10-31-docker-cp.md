# docker-cp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Control panel web ringan (satu binary Go) untuk mengelola Docker, Caddy (reverse proxy + HTTPS), dan terminal di VPS 1–2 GB, dipasang dari GitHub Releases dengan satu skrip.

**Architecture:** Satu proses Go (`docker-cp serve`) yang melayani HTML server-rendered (htmx) dan WebSocket terminal. Panel bicara ke Docker Engine API lewat unix socket memakai client HTTP buatan sendiri yang tipis, memanggil `docker compose` sebagai subprocess, dan mengelola Caddy dengan menyusun Caddyfile utuh lalu `POST /load` ke Admin API. State panel (admin, settings, sites) disimpan di satu file JSON yang ditulis secara atomik. Docker sendiri adalah sumber kebenaran untuk container.

**Tech Stack:** Go ≥ 1.23 (`net/http` ServeMux dengan pola method+path), `html/template` + `embed`, `golang.org/x/crypto/bcrypt`, `github.com/coder/websocket`, `github.com/creack/pty`, htmx 2.x dan xterm.js 5.x (+ `@xterm/addon-fit`) yang di-vendor, GoReleaser + GitHub Actions, bash untuk `install.sh`.

**Spec:** `docs/superpowers/specs/2026-10-31-docker-cp-design.md`. Baca spec ini dulu; plan ini mengacu ke sana.

## Global Constraints

- `CGO_ENABLED=0`. Tidak ada dependensi runtime selain Docker Engine + compose plugin dan Caddy. Tidak ada Node, PHP, Python, atau server DB.
- RSS panel idle tanpa browser ≤ 20 MB (batas keras 50 MB). Dengan 1 tab + 1 terminal ≤ 40 MB (batas keras 80 MB). Anggaran ini hanya untuk proses panel.
- CPU idle ~0%: **tidak boleh ada goroutine ticker/polling latar belakang.** Pembersihan sesi dilakukan secara lazy. Stats dan logs hanya berjalan selama ada klien.
- Binary ≤ 25 MB (batas keras 40 MB), build dengan `-ldflags "-s -w"`.
- Semua aset frontend di-embed. Tidak memakai CDN. Tidak memakai `alert()`/`confirm()` browser; konfirmasi memakai `<dialog>`.
- Path: data `/opt/docker-cp/data/state.json`, stack `/opt/docker-cp/stacks/<nama>/`, Caddyfile `/etc/caddy/Caddyfile`, Caddy admin `http://127.0.0.1:2019`, socket `/var/run/docker.sock`, docker config `/root/.docker/config.json`, binary `/usr/local/bin/docker-cp`.
- Port panel default **8800**. Port container yang disarankan dimulai dari **8001**. Publish default ke **`127.0.0.1`**. Restart policy default **`unless-stopped`**.
- Docker API dipin ke prefix **`/v1.43`**.
- Target OS: Debian 12 / Ubuntu 22.04+, amd64 dan arm64.
- Login: bcrypt cost 12, rate-limit **5 kegagalan per 15 menit per IP**, cookie `dcp_session` (`HttpOnly`, `SameSite=Strict`, `Secure` saat HTTPS), TTL sesi 24 jam. CSRF wajib untuk semua non-GET (header `X-CSRF-Token` atau field form `csrf`). Origin WebSocket harus sama dengan Host.
- UI berbahasa Indonesia.

## Review Focus

1. **Direktif custom berisi `}`** yang menutup blok site lalu membuka site baru (misalnya `}\nevil.com {`) harus ditolak dengan pesan jelas, bukan disisipkan ke Caddyfile. Test: `TestValidateCustomBraces` (Task 7).
2. **Field domain berisi spasi, `{`, huruf besar, titik di akhir, atau domain yang sudah dipakai site lain.** Domain dinormalisasi ke huruf kecil tanpa titik akhir. Karakter ilegal dan duplikat lintas site ditolak. Test: `TestValidateDomains`, `TestValidateDomainsDuplicate` (Task 7).
3. **Target container sudah dihapus atau tidak mem-publish port.** Site itu menghasilkan `respond ... 502` plus warning, dan site lain tetap ter-load. Test: `TestGenerateMissingContainer` (Task 7).
4. **Dua penyimpanan bersamaan, atau crash di tengah penulisan.** `state.json` tidak boleh terpotong dan update tidak boleh hilang. Test: `TestConcurrentUpdates`, `TestAtomicWrite` (Task 2).
5. **Tab ditutup saat terminal atau `logs follow` berjalan.** Proses shell harus mati dan stream log Docker harus ditutup. Test: `TestServeHostKillsOnClose` (Task 11), `TestLogsSSEClosesOnDisconnect` (Task 13).

- `StatsOnce`:
  - `CPUPercent = (cpu_stats.cpu_usage.total_usage − precpu_stats.cpu_usage.total_usage) / (cpu_stats.system_cpu_usage − precpu_stats.system_cpu_usage) × online_cpus × 100`. Kalau penyebutnya 0, hasilnya 0.
  - `MemUsage = memory_stats.usage − memory_stats.stats.inactive_file`.
- `InUse` dihitung dengan mencocokkan `ListContainers`: `ImageID` untuk image, `Mounts[].Name` untuk volume.
- `ExecAttach`:
  1. `POST /exec/{id}/exec` dengan `{"AttachStdin":true,"AttachStdout":true,"AttachStderr":true,"Tty":true,"Cmd":cmd,"Env":["TERM=xterm-256color"]}`.

  3. Baca respons dengan `http.ReadResponse(bufio.Reader)` dan pastikan status 101.
  4. `Conn` = gabungan `bufio.Reader` (sisa data) untuk Read dan `net.Conn` untuk Write/Close.

**Algoritma Recreate** (tidak ditentukan oleh test, jadi ditulis di sini):

4. `Rename(old, name+"-old-"+unix)`.
5. `Create(spec)`. Kalau gagal: `Rename` balik, `Start(old)`, kembalikan error.
6. `Start(new)`. Kalau gagal: `Remove(new,false)`, `Rename` balik, `Start(old)`, kembalikan error.

**`install.sh`** (`set -euo pipefail`; `REPO="${DCP_REPO:-OWNER/docker-cp}"`; flag `--version vX.Y.Z`, `--update`):
1. Wajib root. `/etc/os-release` harus `debian` atau `ubuntu` (atau `ID_LIKE` memuat salah satunya); selain itu keluar dengan pesan.
2. Petakan arsitektur: `uname -m`, `x86_64→amd64`, `aarch64→arm64`.
3. Bila bukan `--update`:
   - Pasang Docker CE + `docker-compose-plugin` lewat repo apt resmi Docker, dilewati bila `docker` sudah ada.
   - Pasang Caddy lewat repo apt resmi Caddy (cloudsmith), dilewati bila sudah ada.
4. Unduh `docker-cp_<ver>_linux_<arch>.tar.gz` dan `checksums.txt` dari `https://github.com/$REPO/releases/latest/download/` (atau `/download/<ver>/`), lalu `sha256sum -c --ignore-missing`. Gagal → batal.
5. `install -m 0755` ke `/usr/local/bin/docker-cp`; `install -d -m 0700 /opt/docker-cp/data /opt/docker-cp/stacks`; pasang unit dan jalankan `systemctl daemon-reload`.
6. Bila bukan `--update`:
   - Baca password dari `/dev/tty` (karena stdin adalah pipe curl) dua kali dan pastikan cocok.
   - Domain panel dan email ACME opsional.
   - Jalankan `printf '%s\n' "$PW" | docker-cp setup --panel-domain … --acme-email …`.
   - Tawarkan ufw (default **tidak**). Kalau ya: `ufw allow <port SSH dari sshd -T | awk '/^port /{print $2}'>`, `80`, `443`, `8800`, lalu `ufw --force enable`.
7. `systemctl enable --now caddy docker docker-cp` (atau `restart docker-cp` saat `--update`). Cetak URL `http://<IP>:8800` dan domain panel bila ada.
